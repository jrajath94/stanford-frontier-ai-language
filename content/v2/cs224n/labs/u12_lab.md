# Lab U12 , tokenization arithmetic in numpy

Six tasks. Run `python3 labs/u12_lab_run.py` from the `cs224n/`
directory. Numpy only. Record the numbers, then read
`labs/u12_lab_key.md` to verify.

T1. BPE: 6 merges on "aaabdaaabac". Report merges and final pieces.
T2. Fertility: 1.3, 1.6, 2.1, 2.8. Report per language.
T3. Zipf coverage: top 1000 of 10000. Report the coverage.
T4. Cost inequality: 24, 30, 41, 58 tokens. Report the ratios.
T5. Morphology: gold vs BPE on "unhappiness". Report agreement.
T6. Code switch: tag the 7-word toy sentence.
