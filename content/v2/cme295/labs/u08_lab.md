# U08 lab , evaluation math in code

Prerequisites: the U08 lesson. Runner: `u08_lab_run.py` (numpy, CPU,
deterministic). Work each task by hand first, then verify with the
runner. Answers and verified outputs: `u08_lab_key.md`.

## Task 1 , debiased win rate

1. Orders give A-win rates 0.70 and 0.45. Compute the
   debiased estimate.
2. State what the 0.25 order gap measures.

## Task 2 , ECE

Confidences [0.55, 0.65, 0.75, 0.85, 0.95], accuracies
[0.55, 0.62, 0.68, 0.75, 0.78], equal bin weights.

1. Compute ECE.
2. Name the worst bin.

## Task 3 , Wilson intervals

1. n = 100, w = 62. Compute the 95% interval.
2. n = 400, w = 248. Compute the interval and state the
   width ratio.

## Task 4 , eval bill

Price $0.002 per judge call, swapped orders.

1. 10 models, 500 items. Compute the bill.
2. 6 models, 200 items. Compute the bill.

## Task 5 , benchmark read

Scores 0.92 vs 0.91, n = 500 each.

1. Compute both 95% bands.
2. State the verdict.
