# Lab U15 , project arithmetic in numpy

Six tasks. Run `python3 labs/u15_lab_run.py` from the `cs224n/`
directory. Numpy only. Record the numbers, then read
`labs/u15_lab_key.md` to verify.

T1. Tiny GPT-2: V=1000, d=8, L=4. Report total params.
T2. Probe: linear fit on random data, 200 steps. Report first
and last loss.
T3. Downstream template: 3 toy scores with SE. Report, labeled
toy.
T4. Scope scorecard: 5 criteria. Report the score.
T5. Seed sweep: 5 seeds. Report mean and std.
T6. Pipeline: name the 4 gates from SRC-04.
