# Lab U14 , multimodality arithmetic in numpy

Six tasks. Run `python3 labs/u14_lab_run.py` from the `cs224n/`
directory. Numpy only. Record the numbers, then read
`labs/u14_lab_key.md` to verify.

T1. Fusion: d = 1024, L = 24. Report late vs early extra params.
T2. Routing: 8 experts, loads given. Report the aux loss.
T3. Token budget: 256 image + 512 text. Report the image share.
T4. Joint cost: 128 text tokens, 20 diffusion steps at 8. Report.
T5. Fused retrieval: scores 0.72/0.41 at w = 0, 0.5, 1. Report.
T6. Claim classes: count the U14 leaves per class.
