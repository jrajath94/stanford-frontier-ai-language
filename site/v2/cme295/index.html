Fast path versus deep reference

The fast path reads each lesson’s items 1-6 (question, model, objects, mechanism, computed toy). The deep reference adds items 7-15 (implementation, checks, complexity, alternatives, failure, research, assessment, lab, figures). The fast path is shorter navigation, not omitted concepts.
